# AI Product Lab

AI product experiments, agents, prototypes, and evaluation frameworks built from a Product Manager's perspective.

This lab documents the full product journey: problem framing, MVP scope, prototype decisions, evaluation, and iteration.

## Projects

### 01 · Sales Avatar

A text-first AI sales simulation that lets a sales rep practice a customer conversation and receive actionable feedback.

**Current version:** V0.1 — one model, one persona prompt, and one evaluation prompt.

[Explore Sales Avatar](projects/sales-avatar/README.md)

## Product principles

- Start with a clear user problem.
- Prove value with the smallest useful prototype.
- Treat evaluation as part of the product.
- Add complexity only when evidence supports it.
